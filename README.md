```
pkg update -y && pkg upgrade -y
``` 
2.
```
pkg install git -y && pkg install python -y 
```
3.
```
git clone https://github.com/RKD-TEAM/Basic-Tool-Install
```
4.
```
cd Basic-Tool-Install
```

```
